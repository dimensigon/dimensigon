# Dimensigon Documentation

Welcome to the comprehensive documentation for Dimensigon - a distributed server management and orchestration platform.

## Overview

Dimensigon (DM) is a powerful backend technology designed for elastic service bootstrapping, featuring:

- Polyglot/Heterogeneous orchestrations
- Mesh networking capabilities
- Decentralized IoT management (IoT 2.0)
- Distributed-decentralized server management
- Full RESTful API
- Distributed vault for configuration and secrets
- Log federation
- Double encryption (SSL + encrypted messaging)
- Granular ACLs on top of OS security
